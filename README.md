# Weekly Java Assignments

This repository contains Java practice assignments organized by difficulty level. Each program is a standalone console application with its own `main` method.

## Repository Structure

- `src/Level 1/`: beginner-level assignments
- `src/Level 2/`: intermediate-level assignments
- `src/Level 3/`: advanced-level assignments
- `questions.txt`: assignment questions and hints
- `.vscode/`: editor settings

## Available Programs

### Level 1

- `Question1.java`: mean height of 11 football players
- `Question2.java`: store odd and even numbers in separate arrays
- `Question3.java`: find and display factors of a number
- `Question4.java`: convert a 2D array into a 1D array
- `Question5.java`: FizzBuzz using an array

### Level 2

- `Question1.java`: employee bonus, old salary, and new salary calculation
- `Question2.java`: find the youngest and tallest among three friends
- `Question3.java`: largest and second-largest digit in a number
- `Question4.java`: dynamic array version of the digit problem

### Level 3

- `Question1.java`: frequency of each digit in a number

## Requirements

- Java JDK 8 or later
- Terminal or command prompt to compile and run Java files

## How to Compile and Run

Because the folder names contain spaces, wrap paths in quotes.

Compile a program:

```powershell
javac "src\Level 1\Question1.java"
```

Run the compiled program:

```powershell
java -cp "src\Level 1" Question1
```

Another example:

```powershell
javac "src\Level 2\Question4.java"
java -cp "src\Level 2" Question4
```

## Notes

- Most programs take input using `Scanner`.
- Programs are grouped by assignment level instead of topic.
- `questions.txt` can be used as the reference for the original problem statements.
